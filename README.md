# Bank Account Management System
A Python OOP project simulating a bank account system.

## concepts Used
- Class & Instance Attributes
- Classmethods & Staticmethods
- Encapsulation of banking operation

## Features
- Create Customer Accounts
- Deposit / Withdraw money
- Check Balance
- Update bank branch/location (class -level changes)
